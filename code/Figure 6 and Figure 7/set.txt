Prior to dimensionality reduction, the feature vectors were standardized using Z-score normalization to ensure balanced contributions from all dimensions during distance calculation. The t-SNE algorithm was implemented using the TSNE class from the scikit-learn library (v1.0.0), consistent with the other data processing steps in the study.

The key parameters configured for the t-SNE analysis were:

n_components: 2

random_state: 42 (to ensure the reproducibility of all stochastic processes, as stated in the experimental setup)

perplexity: 30 (a standard value suitable for the dataset size)

n_iter: 1000 (standard optimization iterations)

init: 'pca' (for stable initialization)

learning_rate: 'auto'

This parameter set aligns with established best practices for achieving stable, interpretable, and reproducible two-dimensional embeddings, which effectively demonstrate the model's capability to separate distinct behavioral clusters.
